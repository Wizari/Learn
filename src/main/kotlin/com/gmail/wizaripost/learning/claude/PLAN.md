# План обучения Kotlin + Spring

Формат: 4-7 ч/неделю, маленькие консольные задачи на каждую тему, затем переход
к проектам с БД/Spring. Java целенаправленно пропускаем — фундамент сразу на Kotlin.

Статусы: ✅ пройдено · 🔶 в процессе · ⬜ не начато

## Как строится урок

1. Объяснение темы с примерами кода.
2. 2-3 практические задачи возрастающей сложности.
3. Решения пишутся прямо в пакет `claude/lessonXXX/...` (при нескольких
   задачах — подпапки `q1`, `q2`, `q3`).
4. Разбор решений: что верно, что можно упростить/идиоматичнее, что доработать.
5. Итог фиксируется в [`PROGRESS.md`](PROGRESS.md), после чего переходим дальше.
